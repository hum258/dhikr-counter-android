# Dhikr Counter

تطبيق أندرويد لعدّ الأذكار صوتياً. يختار المستخدم الذكر أو يكتب ذكراً مخصصاً، ثم يبدأ الاستماع ويُحتسب التكرار عند التعرف على العبارة.

## الحالة
نسخة تأسيسية قيد التطوير. لا تعتبر ميزة الاستماع مع إغلاق الشاشة جاهزة حتى تكتمل خدمة Android الأمامية ويُختبر سلوكها على أجهزة فعلية.

## البناء
يُبنى APK عبر GitHub Actions من تبويب Actions.
